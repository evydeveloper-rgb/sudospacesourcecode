 YANG PERLU KAMU LAKUKAN (1 MENIT)
═══════════════════════════════════════════════

Vercel butuh login browser — tidak bisa otomatis dari sini.

STEP 1 — Login & deploy (satu kali):

  cd sudo-api
  npx vercel login

  Terminal akan tampilkan URL seperti:
    https://vercel.com/oauth/device?user_code=XXXX-XXXX

  Buka URL itu di browser (BUKAN link GitHub lama).
  Login Vercel → klik Authorize → tunggu terminal bilang success.

  Lalu:
  npm run deploy

Script deploy.sh akan otomatis:
  • migrate Neon
  • deploy ke Vercel
  • upload semua env vars
  • buat Stripe webhook
  • update api.url.default

STEP 2 — Re-flash SD card:

  cd ..
  ./prepare-sd.sh

STEP 3 — Test di Pi setelah WiFi setup:

  http://raspberrypi.local/billing.html
