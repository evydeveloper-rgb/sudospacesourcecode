 SUDO FACTORY — STATUS (user flow + agent backend)
═══════════════════════════════════════════════

Hardware: Raspberry Pi 5 (arm64).
Agent brain: OpenClaw. PicoClaw is the on-card FALLBACK until OpenClaw installs.

TARGET FLOW
───────────
  1. Plug Pi → hotspot RaspiSetup appears
  2. Captive portal → pick home WiFi → connect
  3. Pi reboots → installs OpenClaw (first boot), cloud registers device (background)
  4. User opens http://raspberrypi.local/
  5. Onboarding: your name, agent name, personality, model
  6. Chat with real AI (OpenClaw + OpenRouter)
     — until OpenClaw finishes installing, PicoClaw answers so the user isn't stuck
  7. Billing at /billing.html (Stripe, needs Vercel deploy)

WiFi captive portal (real nmcli connect)
  wifi-setup/app.py + templates
  Opens the local dashboard directly after setup

OpenClaw as the agent brain (installs on first boot with WiFi)
  sudo-pi/install-openclaw.sh → pinned 2026.6.11 into /opt/openclaw
  Prefers prebuilt arm64 bundle on the card; falls back to npm
  Needs Node.js >= 22.19 (installed on first boot via NodeSource)
  systemd sudo-openclaw-install.service + sudo-openclaw-gateway.service
  agent_backend() returns "openclaw" whenever /opt/openclaw exists

PicoClaw = on-card fallback only (until OpenClaw is in place)
  picoclaw/picoclaw binary arm64 on SD; systemd picoclaw-gateway.service
  Answers first-boot chat so the box is never talking to nothing

Agent onboarding (real, persisted)
  /onboarding.html → saves /opt/sudo/config.json
  personality + model selection

Real chat UI
  /chat.html → POST /api/agent/chat → active agent (OpenClaw; PicoClaw fallback)

Routing
  / → login (if needed) → onboarding or /chat.html
  /dashboard.html → legacy bundled UI (apps mock)
  /billing.html → Stripe checkout via Pi proxy

Security hardening (offline-capable)
  device_secret at install (no internet)
  Passwordless dashboard; public links must be treated as bearer secrets
  Rate limits (login + chat), CORS lock, security headers
  Cloud API requires X-Device-Id + X-Device-Secret
  Billing proxied through Pi (secret never in browser)
  Public mode: Caddy HTTPS + ufw + bind 127.0.0.1:8080
    sudo sudo-enable-public.sh your.domain.com

Cloud + OpenRouter per device
  sudo-cloud-init → register with device secret → openrouter key
  configure-picoclaw.sh → SOUL.md + picoclaw config

No npm/node/npx needed AFTER install — factory ships the PicoClaw binary;
OpenClaw installs once on first boot (bundle or npm), then runs from /opt/openclaw
