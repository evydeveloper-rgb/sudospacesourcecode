# PENDING — open loops

<!-- sudo:pending-intro -->
Everything you still owe: things you deferred, promised to come back to, or
are waiting on. One line per loop, so the whole list reads at a glance. The
person sees and edits this same list in Home → Tasks.

    - [added YYYY-MM-DD] what's open → next action

Add a line the moment something is deferred or promised. Delete it the moment
it resolves. A status tag at the end is optional — `[status: started]`,
`[status: working]` or `[status: done]`; no tag means open. Anything older than
about 7 days: bring it up with the person, or drop it.
<!-- /sudo:pending-intro -->
