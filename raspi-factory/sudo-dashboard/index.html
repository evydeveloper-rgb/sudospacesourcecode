    What’s on your Sudo today

    Your Sudo already has a brain of its own: Gemma 3 270M, a small model that runs entirely on the device. “270M” means 270 million parameters, the numbers a model learns with. More parameters usually means a more capable model.

    Why about 4 billion on a Pi?

    The Pi 5 in your Sudo has 4GB of memory, shared with everything else it runs. As a rule of thumb that fits a model of roughly 4 billion parameters at most, and only heavily compressed (“quantized”), so each parameter takes about half a byte instead of two. Anything bigger simply doesn’t fit, and even that size answers slowly.

    Our advice The on-device model is fine for a chat. For everyday work like email, research and planning, we recommend a cloud model.

    What your agent is made of

    Memory, context and tools are yours. They’re what your agent knows about you and can do for you, and they grow every day you use it.

    The LLM is the swappable part. AI companies keep leapfrogging each other: one month ChatGPT leads, the next it’s Claude or DeepSeek. With Sudo you’re not locked in. Switch models and keep your memory and context. No starting over.

    OpenRouter: one key, nearly every model

    OpenRouter is one account with one universal API key that reaches nearly every AI model. You top up credit there, and it pays the AI companies for you.

    1. Create an account at openrouter.ai.
    2. Add credit. You choose how much.
    3. Create a key under Keys and paste it into Sudo: Settings → API keys. It starts with sk-or-.
    Sudo takes no cut

    You pay the AI companies through OpenRouter. Your key stays on this device, and we never see your bill.

    other ways to extend sudo
    MCP is an open standard for giving an agent new abilities. An MCP server is a small program exposing tools — read this database, search these docs, control this app — and sudo can call them.

    Composio is the no-setup option; MCP is what you reach for when you want something specific or self-hosted. It runs on your device, so nothing leaves your network.

    Not wired up yet — it needs the same care as running commands, since an MCP server is code you chose to trust.

    Run commands on this device On by default. The agent can use the terminal — install things, edit files, check the system. Switch off to keep it talking only.
    Why it's on. Doing things is the point. With the terminal the agent can actually install, fix and check things on your Pi instead of describing what you could do yourself.

    What you're accepting. It has the same power on this device that you do when you log in. It also reads web pages, and a page can contain text written to trick it into running something — it can't always tell instructions from content. Blocked-command patterns catch obvious attempts, not clever ones.

    When to switch it off. If this Pi holds anything you'd mind losing, or if you've turned on Access from anywhere — that puts the dashboard on a public link with no password, and anyone who has it would be talking to something that can run commands.
    Work with helpers Split big jobs across copies of itself, then combine the results.
    For a job with several parts, {{AGENT}} can start temporary helpers, give each a piece, and gather the answers. Useful for research or anything with a lot of steps.

    It costs more. Every helper is its own conversation and is billed separately, so one request can cost several times a normal message. Limited to 2 helpers at a time.
    Install skills Download ready-made abilities from the ClawHub library.
    Skills are small add-ons other people have written, fetched from clawhub.ai and run on your device.

    They are code from strangers. We don't review them. Leave this off unless you want a specific skill and trust where it came from.
    Full device access Off by default. Lets {{AGENT}} change this dashboard itself, add things to it, and reach anywhere on the device — not just its own workspace.
    Why it's off. Normally {{AGENT}} is boxed into its own workspace — its memory, its notes, nothing else. This takes the box away, the same as running it on a regular computer with no restriction at all.

    What you're accepting. It can rewrite this dashboard, install things, and change anything on the device — genuine ownership, but with no undo button if an edit goes wrong. It also means it could, if asked the right way by whoever it's talking to, read its own configuration file out loud — and that file holds your live API key. Treat it as equivalent to handing out that key.

    When to turn it on. When you want it building or changing things here yourself, and you've accepted that a bad edit is yours to fix — the same trust you'd put in a program you run directly on your own machine.
    Speak up on its own On by default. {{AGENT}} can message you first now and then — a reminder about something you said you'd do, or a reply you're waiting on. Most checks end in silence.
    What it does. Every half hour {{AGENT}} takes a cheap look at what it knows about you and decides whether there is anything genuinely worth sending. If there isn't, it stays quiet — you won't get a scheduled "just checking in".

    Only after you've messaged it. It never opens a WhatsApp conversation by itself. Until you write to it once there is nowhere to send, and it does nothing. No messages between 22:00 and 08:00.

    Why it's on. An agent that only ever answers is a search box. Speaking first is what makes it feel like it's actually paying attention. Switch it off if you'd rather it stayed silent unless spoken to.

    A safety cap on how much {{AGENT}} talks to the paid model. Past the limit it pauses itself until tomorrow, so a runaway loop or a curious kid can't burn through your API budget.

    Pause when the limit is hit On by default. Switch off to remove the cap entirely — you keep full control of your own device, but nothing stops a runaway.
    What it does. Every message to {{AGENT}} costs a little, and a stuck loop can spend a lot before anyone notices. This counts those calls right here on the device and stops them once you've hit the daily number.

    No dollar guessing. It counts messages, not money, and it never sees your key or touches the network — the count lives on your Pi.

    It can't lock you out. If anything goes wrong reading the count, it lets the message through. Worst case you're back to no cap, never a bricked agent.
