        How on-device models work
        
            
        
              
        
                
                  
                  Parameters: what the “B” meansSize is knowledge, and memory
                
                
        
                  
        A parameter is one number the model learned in training. 1.7B means 1.7 billion of them. More parameters hold more knowledge and follow instructions better, but take more memory and run slower.
        
                  
        
                    
        Gemma 3 270M
        0.27B
        
                    
        Qwen3 1.7B
        2B
        
                    
        Qwen3 14B
        15B
        
                    
        Cloud models
        500B+
        
                  
        
                  
        The scale is squeezed: the cloud bar stands for about 250 times Qwen3 1.7B. Cloud models run on data-centre hardware, which is why they are so much smarter.
        
                
        
              
        

              
        
                
                  
                  Quantization: shrinking a model to fitWhy a 2B model is a 1.4 GB file
                
                
        
                  
        Each parameter is stored as a number. Fresh from training it takes 16 bits. Quantization rounds it to 8 or 4 bits: the file shrinks by half or three quarters, and quality drops a little.
        
                  
        
                    
        16-bit
        4.1 GBOriginal
        
                    
        8-bit
        2.2 GBAlmost no difference
        
                    
        4-bit
        1.4 GBSmall loss, rarely noticed
        
                  
        
                  
        Qwen3 1.7B at each precision. Below 4 bits, answers get noticeably worse.
        
                  
        Reading a name like Q4_K_M
        
                  
        
                    
        Q44 bits per weight
        
                    
        K“k-quant”: weights in small blocks, each with its own scale, so rounding errors stay small
        
                    
        MMedium: a few sensitive layers kept at 6 bits (S = fewer, L = more)
        
                  
        
                  
        File size ≈ parameters × bits ÷ 8
        
                
        
              
        

              
        
                
                  
                  Speed: why bigger is slowerMemory speed sets the pace
                
                
        
                  
        To write each token (about ¾ of a word), the model reads every one of its weights from memory once. So the Pi’s memory speed, not its processor, sets the pace.
        
                  
        
                    
        ≈ 9 GB/sPi 5 memory
        
                    ÷
                    
        1.4 GBmodel file
        
                    ≈
                    
        6 tokens/swriting speed
        
                  
        
                  
        You read about 4–5 tokens a second, so anything above that feels live. Before writing, the model also reads your message and the chat so far, so long chats take longer to start.

                  Run commands on this device
                  On by default. The agent can use the terminal — install things, edit files, check the system. Switch off to keep it talking only.
                
        
                
              
        
              
              
        
                Why it's on. Doing things is the point. With the terminal the agent can actually install, fix and check things on your Pi instead of describing what you could do yourself.

        
                What you're accepting. It has the same power on this device that you do when you log in. It also reads web pages, and a page can contain text written to trick it into running something — it can't always tell instructions from content. Blocked-command patterns catch obvious attempts, not clever ones.

        
                When to switch it off. If this Pi holds anything you'd mind losing, or if you've turned on Access from anywhere — that puts the dashboard on a public link with no password, and anyone who has it would be talking to something that can run commands.
              
        
              
        
                
        
                  Work with helpers
                  Split big jobs across copies of itself, then combine the results.
                
        
                
              
        
              
              
        
                For a job with several parts, sudo can start temporary helpers, give each a piece, and gather the answers. Useful for research or anything with a lot of steps.

        
                It costs more. Every helper is its own conversation and is billed separately, so one request can cost several times a normal message. Limited to 2 helpers at a time.

                Skills are small add-ons other people have written, fetched from clawhub.ai and run on your device.

        
                They are code from strangers. We don't review them. Leave this off unless you want a specific skill and trust where it came from.
              
        

              
        
                
        
                  Full device access
                  Off by default. Lets sudo change this dashboard itself, add things to it, and reach anywhere on the device — not just its own workspace.
                
        
                
              
        
              
              
        
                Why it's off. Normally sudo is boxed into its own workspace — its memory, its notes, nothing else. This takes the box away, the same as running it on a regular computer with no restriction at all.

        
                What you're accepting. It can rewrite this dashboard, install things, and change anything on the device — genuine ownership, but with no undo button if an edit goes wrong. It also means it could, if asked the right way by whoever it's talking to, read its own configuration file out loud — and that file holds your live API key. Treat it as equivalent to handing out that key.

        
                When to turn it on. When you want it building or changing things here yourself, and you've accepted that a bad edit is yours to fix — the same trust you'd put in a program you run directly on your own machine.
              
        

              
        
                
        
                  Speak up on its own
                  On by default. sudo can message you first now and then — a reminder about something you said you'd do, or a reply you're waiting on. Most checks end in silence.
                
        
                
              
        
              
              
        
                What it does. Every half hour sudo takes a cheap look at what it knows about you and decides whether there is anything genuinely worth sending. If there isn't, it stays quiet — you won't get a scheduled "just checking in".

        
                Only after you've messaged it. It never opens a WhatsApp conversation by itself. Until you write to it once there is nowhere to send, and it does nothing. No messages between 22:00 and 08:00.

        
                Why it's on. An agent that only ever answers is a search box. Speaking first is what makes it feel like it's actually paying attention. Switch it off if you'd rather it stayed silent unless spoken to.
              
        
              
        
            
        
          
        
          
        
            
            
        
              
        A safety cap on how much sudo talks to the paid model. Past the limit it pauses itself until tomorrow, so a runaway loop or a curious kid can't burn through your API budget.
        

              
        
                
        
                  Pause when the limit is hit
                  On by default. Switch off to remove the cap entirely — you keep full control of your own device, but nothing stops a runaway.
                
        
                
              
        
              
              
        
                What it does. Every message to sudo costs a little, and a stuck loop can spend a lot before anyone notices. This counts those calls right here on the device and stops them once you've hit the daily number.

        
                No dollar guessing. It counts messages, not money, and it never sees your key or touches the network — the count lives on your Pi.

        
                It can't lock you out. If anything goes wrong reading the count, it lets the message through. Worst case you're back to no cap, never a bricked agent.

                  Keep it on this device
                  Answer with the on-device model even when a key is saved. Nothing you type leaves the house.
                
        
                
              
        
              
              
        
                The on-device model is small — roughly a thousandth the size of the cloud ones. It can greet you, chat, and handle simple things. It cannot search the web, reason through anything long, or look at images.

        
                It costs nothing to run and works with the internet down.

        
                If it is not installed yet, messages still go to the cloud rather than failing.
              
        
              
        
              
        
                
                
              
        

              
              
        
                Short and simple asks go to the cheapest text model, which is where most messages land.

        
                Anything with an image goes to a model that can actually see — the default is text-only, so without this it would just guess.

        
                Long or multi-step work steps up to a stronger model, because a cheap model looping on a hard task costs more than the good model doing it once.

        
                You are billed per message, so automatic usually costs less than pinning everything to one strong model.

                GPT-4o mini — cheap and quick, and can read images.

                Claude Sonnet 4.5 — the strongest here and the most expensive. Best for tricky, multi-step work.
